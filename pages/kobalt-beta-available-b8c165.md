### 1. Installing Kobalt

- Go to [the website](https://kobalt.nicoverbruggen.be/?ref=rogerprice.me) and choose **Install or Modify Kobalt** (lines 10–11).
- In the wizard: tick the checkbox, click **Continue** (lines 11–12).
- **Google Chrome is required** (line 12).
- Select your Kobo; the OS will prompt you to pick the Kobo's volume — choose the one named **"KOBOeReader"** — then allow access in Chrome (lines 13–15).
- On success, the page displays device information: **model, software version, and whether Kobalt is installed** (lines 15–16).
- Press **Install**; the website copies all files to the Kobo, validates that they are present, then prompts you to eject (lines 16–18).
- **Eject properly** — via Finder, Windows Explorer, or your Linux file manager — and do not unplug until ejection succeeds (lines 18–19).
- After the "congratulations" message, allow a minute or two before the Kobo shows its home screen again (lines 19–21).

### 2. Using Kobalt

**DRM handling**

- Protected books open in **Kobo's normal reader** instead, because Kobalt only opens **DRM-free EPUB files** (lines 22–24).
- The presenter's copy of *The Way of Kings*, bought from the Kobo Store, works because publisher **Tor** released it DRM-free (lines 24–26).
- First opening takes longer — Kobalt loads the **entire book**, not just a single chapter — after which it is quick (lines 26–27).

**Main menu** (tap the middle of the screen) (lines 27–28)

| Menu | Function |
| --- | --- |
| Chapter list | Shows your position; jump to any chapter |
| Text | Adjust text appearance; pick a new font (the presenter notes "Libron" may be familiar) |
| Layout | Set margins, rotate the reader, set header, footer and clock |
| Light | Controls the front light |
| Stats | Position in book and chapter, plus reading time |

**Gestures and navigation**

- Brightness gesture on the left; warmth gesture on the right — a personal favourite of the presenter (lines 33–34).
- Page turning: tap the left side to go back, the right side to go forward, or use the page turn buttons (lines 34–36).
- Top-right corner gives quick access to **dark mode** and **bionic reading**, plus a few other settings the presenter recommends exploring (lines 36–39).
- Dark mode is easy to toggle off; bionic reading takes a while to update the book but "looks really great" — the presenter has read that many people can read much faster this way (lines 39–42).

**Not ready yet / roadmap**

- **Highlights and annotations are not in the beta** — described as big omissions (lines 42–43).
- The presenter would like to add **appearance presets**, letting users save favourite settings and apply them to another book (lines 43–45).
- **KOReader Sync** is planned for the future, described as a very common request (lines 45–46).

### 3. Uninstalling Kobalt

Three methods are covered (line 46):

1. **Via the website (easiest):** connect over USB, follow the same procedure as installation, but select **"Remove"** instead of "Install". Eject and unplug — Kobalt restarts your device, and is removed once detected (lines 47–50).
2. **Manually:** in your file explorer, go to the **`.adds/kobalt`** folder, find the file named **"uninstall"**, remove it, then safely eject the Kobo — this causes Kobalt to remove itself (lines 50–53).
3. **Factory reset (last resort):** this resets the entire e-reader, so it is not advised unless you do not expect to be able to restore it the normal way (lines 53–56).

For device-specific instructions, the presenter directs viewers to **Kobo's website** for the latest and most accurate guidance (lines 56–58).
